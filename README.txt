AIRA — public landing page
==========================
Preview: extract the ZIP and double-click index.html. No installation needed.
All assets are local. The four interactive feature demos use sample data, not live AI.

Publish free with GitHub Pages:
1. Sign into github.com and create a public repository, e.g. aira-website.
2. Upload the CONTENTS of this folder (index.html, style.css, app.js, config.js, assets folder, and .nojekyll) to the root of the repository, not a nested folder.
3. Commit the files. Go to Settings > Pages. Under Build and deployment choose Deploy from a branch; select main and /(root); Save.
4. Once deployment finishes, open the actual public URL displayed in Settings > Pages (usually https://YOUR-USERNAME.github.io/aira-website/). Check it on your phone, then use that URL for Hub71 if accepted by the application.

Optional launch-interest form:
Create a Google Form with an email field, a clear opt-in to receive launch updates, and a privacy notice identifying who collects the data, what it is used for, how to unsubscribe and how to contact you. Publish it and set waitlistUrl in config.js to its public HTTPS responder link. Test that submissions reach your own Google account, and don't collect payment or preorders. With no URL configured, the site explicitly says the list is not yet open.
Set contactEmail in config.js to your confirmed Aira business email. By default no email address is shown. Commit the edited config.js to update the hosted site.

No private API keys, user data collection, cookies, or tracking scripts are included. Never put a secret API key in a public website or repository.
The images are previously generated product concepts, not physical prototype photos. Product specifications and availability are not verified. No online shop or paid orders are enabled.
